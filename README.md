Welcome to my professional Quality Assurance Portfolio website. This portfolio is designed with a premium cyber-tech theme representing a QA testing console, featuring interactive automation test simulators and a structured bug reporting system.

---

## 🚀 Key Features

*   **Interactive QA Terminal Sandbox:** Visitors can run mock end-to-end Cypress regressions, check mock API responses, and review my core skills using terminal commands.
*   **"Report a Bug" Contact Form:** A creative twist on the standard contact form. Forms are triaged and outputted as a JIRA-style JSON bug ticket in real-time.
*   **Performance Metrics Visualizer:** Highlights core Quality Assurance indicators, including a **83.33% Defect Removal Efficiency (DRE)** benchmarked from my goals at OttoDigital.
*   **Modern Responsive Layout:** Sleek dark-mode aesthetic with glassmorphism elements, CSS animations, and full adaptation to mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

*   **Core Structure:** Semantic HTML5
*   **Styling & Design:** Vanilla CSS3 (Custom Grid Layouts, Glassmorphism, CSS Transitions & Keyframes)
*   **Logic & Interactions:** Vanilla JavaScript (ES6+, DOM manipulation, Intersection Observer API)

## 🕹️ Interactive CLI Commands
Inside the **Sandbox Environment** section on the website, you can type the following commands into the terminal prompt:

*   `help` - List all available terminal actions.
*   `run-tests` - Launch a simulated Cypress regression suite checking structural layout and link integrity.
*   `check-api` - Execute mocked Postman API integrations and status checks.
*   `skills` - Display my QA expertise matrix in an ASCII table.
*   `version` - Output the current build and client CLI version.
*   `clear` - Wipe the console log.

## 💻 Local Development

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tutiani/qa-portfolio.git
   cd qa-portfolio
   ```

2. **Start a local server:**
   You can run a simple server using Python:
   ```bash
   python3 -m http.server 8282
   ```

3. **View the website:**
   Open your browser and navigate to `http://172.10.66.13:8282`.
